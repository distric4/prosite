# Контекст проекта

## Что это
Сайт-визитка/лендинги, собирается из `src/` (Nunjucks `.njk`) в `docs/` и деплоится на GitHub Pages (CNAME + .nojekyll уже настроены).

## Структура
- `src/` — исходники: `.njk`-шаблоны, `src/_includes/base.njk` — базовый шаблон, `src/styles/`, `src/js/`
- `docs/` — собранная версия (коммитится для GitHub Pages)
- Ниши: `src/nishi/kosmetologiya.njk`, стоматология и др. → `docs/nishi/...`
- Есть в разработке: `src/new.njk` → `docs/new/`, стили `home.css`, `premium.css`, скрипты `home.js`, `premium.js`
- `brief.md` — бриф проекта

## Правила работы (режим экономии токенов)
- Отвечать кратко, только суть и код
- Без скриншотов и лишних тестов; проверки — программно (консоль/DOM/CSS)
- Список правок вносить за один раз, без лишних перечитываний файлов
