## Что уже сделано (хронология)
1. **Выгрузка с Tilda:** скачаны все 7 (сейчас 6) страниц + 200+ ассетов. Антибот Tilda обходится заголовком `Referer`. Часть файлов Tilda отдавала gzip — качать с `curl --compressed`, иначе битый JS.
2. **Относительные пути + SVG-иконки вшиты как `data:`-URI** (CSS-переменные `--icon` резолвились неверно между таблицами — вшивка решила).
3. **Убрано тильдовское брендирование:**
   - Плашка «Made on Tilda» — Tilda вставляет её скриптом с инлайн-`!important`, поэтому в каждой странице сидит сторож (MutationObserver в конце `<body>`), удаляющий `.t-tildalabel`/`#tildacopy` при появлении.
   - Пинг аналитики `tildaapi.com` — удалён.
   - Фавикон Tilda → свой зелёный `data:`-URI фавикон.
4. **Убраны внешние запросы к Tilda** (патчи в локальных minified JS):
   - `tilda-scripts` — URL картинки плашки → прозрачный 1×1 `data:`.
   - `tilda-phone-mask` — флаги телефона → **локальный спрайт** `assets/static.tildacdn.pub/lib/flags/flags7.png`.
   - `tilda-zero-forms` и `tilda-contact-method` — загрузка phone-mask и `tilda-zero-form-errorbox.min.css` перенаправлена на локальные копии.
   - Остаётся лишь шрифт **Manrope с Google Fonts** (не Tilda, безопасно).
5. **Картинки пережаты на месте** (−25%) через `sharp@0.32.6` (ставится во временную папку; Node 19 несовместим с sharp 0.33 — брать 0.32.x).

## Формы → почта (ВАЖНО понимать механику)
На `index.html` **три формы Tilda**:
- `form1915866021` — квиз «Рассчитать стоимость»
- `form1921499261` — контактная/тариф (виджет мессенджера)
- `form1912326261` — форма аудита (ссылка на сайт + имя + телефон)

**Ключевой нюанс:** Tilda отправляет формы **AJAX-запросом на `forms.tildaapi.com/procces/` ПО КЛИКУ** на кнопку submit, а **не** через нативное событие `submit`. Поэтому перехват сделан **на клик**.

**`assets/leadmail.js`** (подключён в конце `index.html`):
- Перехватывает клик по `[type="submit"]` в capture-фазе → `preventDefault` + `stopImmediatePropagation` (блокирует отправку на Tilda).
- Сетевой предохранитель: глушит любые XHR/fetch к `tildaapi.com/procces` / `forms.tilda`.
- Собирает поля формы в читаемое письмо (телефон берёт из готового поля `Phone`; служебные `tildaspec*`, `formservices` и т.п. отбрасывает) и шлёт через **Web3Forms** на почту.
- Показывает «спасибо» (родной success-box Tilda, либо своё сообщение для квиза).
- **Web3Forms access key (публичный, для клиентского кода):** `cf3863c7-4967-4e9d-a65a-1d080192c678` → письма на `aleksey.dianov.1996@gmail.com`. Лимит 250 заявок/мес.
- Квиз не ломается: кнопки «Далее» = `type="button"` (не ловятся), финальная «Получить результат» = `type="submit"` (ловится).

После правок JS на живом сайте проверять с **Ctrl+F5** (кэш браузера).
